# 2023年省级GDP数据调研计划

## 调研目标
1. 获取国家统计局官方发布的2023年各省级行政区GDP总量数据
2. 提取GDP总量前6名省份的具体数值（亿元）及同比增速（%）
3. 获取2023年全国GDP总量数据
4. 计算六省GDP总和
5. 计算各省占全国GDP的比重
6. 按同比增速从高到低进行排名

## 调研步骤
1. 搜索国家统计局官网2023年国民经济和社会发展统计公报
2. 查找各省级行政区GDP数据表格或相关报道
3. 验证数据来源的权威性和时效性
4. 收集全国GDP总量数据
5. 整理前6名省份的GDP数据
6. 进行必要的计算分析

## 数据验证要求
- 优先使用国家统计局官方网站（www.stats.gov.cn）数据
- 其次参考国务院新闻办公室发布会实录
- 避免使用第三方媒体转载的未经核实数据
- 注意数据发布时间（应为2024年初发布）
